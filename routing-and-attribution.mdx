## Routing

Auto-routing (Vertical 2) is **rule-based and deterministic** (a complexity scorer ported from
an existing MIT-licensed open-source implementation) — zero network calls, so the same prompt
always resolves to the same tier and the same model, which matters because the candidate set
feeds a signed receipt. It scores prompt complexity, picks the **cheapest model that clears the
required tier**, and never silently falls back to a model below the floor. An auto-routed
request's digest binds identity + prompt only — never a caller-invisible candidate set the
gateway happened to discover on its own, so two auto-routed calls with the same prompt share a
digest regardless of which models happened to be configured that day.

## Cost attribution

Money is an integer (micro-USD) end to end — never a float. The ledger is a real append-only
event log (`reserve` → `commit` / `release` / `correct`) with an optimistic version guard on
`budget_balances`, specifically because a mutable spend counter loses updates across a
multi-second provider call under concurrency. `packages/web` renders a server-side admin UI on
top of this: virtual keys, per-team budgets (with a real `setLimit` ledger event, not a raw
`UPDATE`), and a read-only policy view.

## Audit receipts

Every receipt is signed as a flattened JWS (Ed25519/EdDSA) over RFC 8785 canonical JSON — never
HMAC, because HMAC would mean only *we* can verify our own receipts, which defeats the entire
premise. `packages/verifier` re-implements canonicalisation independently and imports nothing
from the producing code (`packages/attest`/`packages/gateway`) — enforced by
`npm run test:boundary` — so a bug in one side's canonicalisation can't quietly agree with
itself.

`packages/evidence` compiles receipts and coverage declarations into bundles with three
possible verdicts per control: `satisfied`, `not_evidenced`, or **`indeterminate`** — "we
weren't watching" — which is never silently upgraded to `satisfied`. The auditor export package
enumerates every evidence artifact under a single digest commitment, so a record that's
silently *missing* is detectable the same way a *tampered* one is — change one number, get
`ADVERSE`; delete one record entirely, and the enumeration commitment itself no longer matches.

## Provider support

**8 native adapters:** Gemini, OpenAI, Anthropic, Anthropic-via-compression-proxy
(`AnthropicTokenOpsAdapter`), Azure OpenAI, Cohere, Vertex AI, and a deterministic Mock (used
throughout the test suite).

**44 OpenAI-compatible endpoints**, wired generically through one adapter and only instantiated
if their API key env var is actually set: Groq, Together, DeepSeek, Mistral, Fireworks,
OpenRouter, Perplexity, DeepInfra, Cerebras, xAI, Moonshot, Baseten, Novita, Hyperbolic,
SambaNova, Nebius, NVIDIA NIM, GitHub Models, Featherless, Friendli, GMI Cloud, Zhipu,
DashScope, Baidu Qianfan, Doubao, Writer, SiliconFlow, Poe, Scaleway, HuggingFace, AI/ML API,
Kluster, Chutes, Venice, Parasail, OVHcloud, Infercom, CloudRift, Martian — plus **local
runtimes with no API key at all**: Ollama, LM Studio, vLLM, LocalAI, text-generation-webui.

Adding provider N+1 touches **only** `packages/gateway/src/providers/` — write a
`ProviderAdapter`, register it, add a `price_book` row. No change to the ledger, `attest`,
`verifier`, or schemas.
